### Описание и инструкция по запуску проекта

### Описание
Проект — это Telegram-бот для регистрации пользователей на мероприятия. Основные функции:
- Регистрация пользователя после вступления в группу Telegram.
- Отмена регистрации.
- Администратор может просмотреть список зарегистрированных пользователей с ссылками на их профили.
- Бот хранит данные о пользователях в базе данных SQLite.

### Требования
1. Python 3.10 или выше.
2. Установленные зависимости из `requirements.txt`.

### Установка и настройка

1. **Клонируйте репозиторий или скопируйте файлы проекта:**
   ```bash
   git clone <repository_url>
   cd <project_directory>
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate    # Linux/MacOS
   venv\\Scripts\\activate     # Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env` и настройте переменные окружения:**
   В корне проекта создайте файл `.env` и добавьте в него:
   ```env
   BOT_TOKEN=your_bot_token
   TELEGRAM_GROUP_USERNAME=your_group_username
   DATABASE_URL=sqlite+aiosqlite:///./users.db
   ADMIN_ID=your_admin_telegram_id
   ```

   - `BOT_TOKEN`: Токен вашего Telegram-бота.
   - `TELEGRAM_GROUP_USERNAME`: Имя вашей группы Telegram (без символа `@`).
   - `DATABASE_URL`: Путь к базе данных SQLite.
   - `ADMIN_ID`: Telegram ID администратора бота.

5. **Инициализируйте базу данных:**
   База данных создаётся автоматически при первом запуске бота. Убедитесь, что путь, указанный в `DATABASE_URL`, корректен.

6. **Запустите бота:**
   ```bash
   python bot.py
   ```

### Использование
- После запуска бот готов к работе. Пользователь может взаимодействовать с ботом через команды или клавиатуру:
  - `/start` — Запустить бота.
  - `/help` — Получить справку.
  - `/register` — Зарегистрироваться на мероприятие (требуется вступление в группу).
  - `/cancel` — Отменить регистрацию.
  - `/view` — Просмотреть зарегистрированных пользователей (только для администратора).

### Примечания
- Убедитесь, что у вашего бота есть права администратора в группе Telegram, указанной в `TELEGRAM_GROUP_USERNAME`, для проверки статуса пользователей.
- Для обновления структуры базы данных используйте SQLAlchemy или пересоздайте базу данных вручную.
